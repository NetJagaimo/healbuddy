# healbuddy 專案計劃書

## 1. 一句話說明
一個手機上用的「多吃紀錄本」：只記**額外吃了什麼**和**做了什麼運動**，正餐不記、也不算卡路里。見 [[額外攝取記帳]]、[[不記卡路里]]。

原則：[[有紀錄比沒紀錄好]]。

## 2. 目標與非目標

| 目標 | 非目標（現階段） |
|---|---|
| 3 秒內記下一杯飲料 / 一包零食 | 記錄三餐、卡路里、營養素 |
| 一鍵打卡今天有運動 | 記錄運動時長、距離、心率 |
| 一眼看出今天 / 本週 / 本月的狀況 | 帳號、雲端同步、跨裝置 → [[離線使用]] |
| 手機安裝、離線可用 → [[PWA]] | 上架 App Store / Google Play |
| | 預設食物品項、首次使用引導、備份提醒 |

## 3. 核心概念

```
  正餐 ─────────────────────────── 不記錄
  多吃（飲料、零食、宵夜…）────── 記品項，計「樣數」
  運動（健身房、爬山、走路8000步+、游泳）── 記項目，同日可多項
```

每天依多吃的樣數顯示 [[胖胖等級]]，有運動就並列運動 emoji：

| 當天多吃 | 0 樣 | 1–2 樣 | 3–4 樣 | 5 樣以上 |
|---|---|---|---|---|
| 顯示 | （無） | 🐹 | 🐷 | 🦛 |

| 運動 | emoji |
|---|---|
| 健身房 | 🏋 |
| 爬山 | ⛰ |
| 游泳 | 🏊 |
| 走路 8000 步 | 🚶 |

相關規則：[[運動打卡規則]]、[[午夜換日]]、[[週日起算]]、[[補登紀錄]]。

## 4. 功能清單

| # | 功能 | 說明 | 優先 |
|---|---|---|---|
| F1 | 食物品項管理 | 新增 / 改名 / 刪除品項（只有名稱） | MVP |
| F2 | 記錄多吃 | 點品項即記一筆，顯示可復原提示；首頁依常用排序只顯示前 8 個 | MVP |
| F3 | 運動打卡 | 4 個預設項目按鈕，按下 = 今天有做；再按取消；可多選 | MVP |
| F4 | 今日紀錄 | 首頁列出今天記了什麼 | MVP |
| F5 | 紀錄頁 | 今日 / 本週 / 本月三個檢視，含胖胖等級與運動 emoji；今日檢視可刪除、補登 | MVP |
| F6 | 資料匯出 / 匯入 | JSON 手動備份（因為沒有同步） | MVP |
| F7 | 運動項目管理 | 改名、換 emoji、新增、刪除運動項目 | MVP |
| F8 | 安裝提示 | 首頁可關閉的安裝卡片、品項頁常駐；支援時一鍵安裝，否則依平台顯示步驟，見 [[PWA安裝提示]] | MVP |

## 5. 介面草圖（手機直向）

底部分頁順序：今日 → 紀錄 → 品項。

### 5.1 首頁：快速記錄 + 今日紀錄

```
┌─────────────────────────────┐
│  9月26日（五）                │
├─────────────────────────────┤
│  吃了什麼？（依常用排序）      │
│  [珍奶] [啤酒] [洋芋片]       │
│  [雞排] [鹹酥雞] [可樂]       │
│  [蛋糕] [餅乾]  [更多 ▾]      │
├─────────────────────────────┤
│  運動了嗎？                   │
│  [🏋 健身房]  [⛰ 爬山 ]       │
│  [🚶 8000步]  [🏊 游泳✓]      │
├─────────────────────────────┤
│  今日紀錄                     │
│  珍奶              15:20  ✕  │
│  啤酒              21:05  ✕  │
│  🏊 游泳                  ✕  │
├─────────────────────────────┤
│ ┌─────────────────────────┐ │
│ │ 已記錄 啤酒      [復原]  │ │ ← 約 5 秒後消失
│ └─────────────────────────┘ │
├─────────────────────────────┤
│  [ 今日 ]  [ 紀錄 ]  [ 品項 ] │
└─────────────────────────────┘
```

首頁只顯示最近常用的前 8 個品項，其餘在「更多」裡，見 [[常用品項排序]]。每次記錄、刪除都有可復原提示，見 [[復原提示]]。

### 5.2 紀錄頁：今日（可刪除、補登）

```
┌─────────────────────────────┐
│  [ 今日 ]   本週    本月      │
├─────────────────────────────┤
│  ◀   9月24日（三）   ▶        │
│                              │
│         🐷  🏋               │
│                              │
│  多吃                         │
│   珍奶                    ✕  │
│   雞排                    ✕  │
│   洋芋片                  ✕  │
│  運動                         │
│   🏋 健身房               ✕  │
│                              │
│      [ ＋ 補登這一天 ]        │
└─────────────────────────────┘
```

點「＋ 補登這一天」，從底部滑出補登面板：

```
┌─────────────────────────────┐
│  補登 9月24日（三）       ✕  │
├─────────────────────────────┤
│  吃了什麼？                   │
│  [珍奶] [洋芋片] [啤酒]       │
│  [雞排] [鹹酥雞] [＋]         │
│  運動了嗎？                   │
│  [🏋 健身房✓] [⛰ 爬山 ]      │
│  [🚶 8000步 ] [🏊 游泳 ]      │
├─────────────────────────────┤
│  點一下就記入 9/24            │
└─────────────────────────────┘
```

刪除後底部出現「已刪除・復原」提示幾秒，不跳確認視窗。只能補登今天和過去的日期。見 [[補登紀錄]]。

## 6. 技術架構

| 層面 | 選擇 | 實體 |
|---|---|---|
| 形式 | PWA（可安裝、可離線） | [[PWA]] |
| 框架 | Svelte 5 + Vite + vite-plugin-pwa | [[Svelte]] |
| 資料 | 瀏覽器 IndexedDB，只存本機，JSON 匯出備份 | [[離線使用]] |
| 部署 | GitHub Pages + GitHub Actions | [[github.io架站]] |
| 測試 | Vitest、Testing Library、Playwright | [[前端測試]] |

資料模型：

```
FoodItem      { id, name, createdAt }
IntakeEntry   { id, date, foodItemId, name, time? } // name 複製一份，品項改名 / 刪除不影響舊紀錄；補登的紀錄 time 為空
ExerciseType  { id, name, emoji }
ExerciseCheck { date, exerciseTypeId, name, emoji } // (date, exerciseTypeId) 唯一；name / emoji 複製一份
// date 一律為本地時間 YYYY-MM-DD，00:00 換日
```

# 復原提示

## 決策
每次記錄或刪除後，按鈕給出即時回饋，並在畫面底部顯示幾秒提示，可一鍵復原：
- 記錄：「已記錄 珍奶・復原」
- 刪除：「已刪除 珍奶・復原」

## 原因
點一下就記錄很容易誤觸，卻沒有回饋；使用者採納「記錄後顯示可復原提示」的建議。刪除則沿用 [[補登紀錄]] 中「不跳確認、改用復原」的做法，兩者統一。

## 範圍與限制
- 適用：首頁快速記錄、補登面板、運動打卡 / 取消、刪除紀錄。
- 提示約 5 秒後自動消失；新的提示會取代舊的，只能復原最近一次操作。
- 不包含：確認視窗、多步驟的復原歷史。

## 對實作的影響
- 共用一個 toast 元件與「最近一次操作」的狀態，復原即執行反向操作。
- 被點的按鈕要有短暫的視覺回饋（閃一下 / 縮放）。
- 測試：記錄 → 復原後資料消失；刪除 → 復原後資料回來；連續操作只復原最後一次，見 [[前端測試]]。

## 考慮過的替代方案
- 每次記錄前跳確認視窗 — 太慢，違反 [[有紀錄比沒紀錄好]]。

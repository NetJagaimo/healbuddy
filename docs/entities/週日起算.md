# 週日起算

## 決策
紀錄頁的「本週」與「本月」月曆都以星期日為一週的第一天（日、一、二…六）。

## 原因
依使用者確認過的紀錄頁草圖（本週列表與月曆皆從「日」開始）。

## 範圍與限制
- 「本週」= 包含所選日期的那個星期日到星期六。
- 月曆每列 7 格，月份外的格子留空。

## 對實作的影響
- `weekDays()`、`monthGrid()` 以 `getDay()`（週日 = 0）計算。
- 單元測試涵蓋週日、週六邊界，見 [[前端測試]]。

## 考慮過的替代方案
- 週一起算（ISO 週）— 草圖採週日起算。

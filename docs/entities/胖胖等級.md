# 胖胖等級

## 決策
依當天「多吃了幾樣」顯示一個 emoji：

| 當天多吃 | emoji |
|---|---|
| 0 樣 | 不顯示 |
| 1–2 樣 | 🐹 |
| 3–4 樣 | 🐷 |
| 5 樣以上 | 🦛 |

當天有運動時，另外顯示該運動的 emoji（多項就並列）。

## 原因
[[不記卡路里]] 之後，需要一個不看數字也能一眼看出當天狀況的方式；使用者選擇用可愛的動物 emoji 依樣數分級。

## 範圍與限制
- 「樣」= 當天的額外攝取紀錄筆數（同一品項記兩次算兩樣）。
- 用於紀錄頁的今日 / 本週 / 本月檢視；首頁不顯示。
- 運動不會抵銷胖胖等級，兩者分開顯示。

## 對實作的影響
- 等級計算為純函式 `level(count)`，門檻 2 / 4。
- 單元測試需涵蓋 0、1、2、3、4、5 樣的邊界，見 [[前端測試]]。

## 考慮過的替代方案
- 紅黃綠燈號（依熱量收支）— 需要卡路里，與 [[不記卡路里]] 衝突。
- 😋 / 🐷 / 🐘 — 使用者改為 🐹 / 🐷 / 🦛。

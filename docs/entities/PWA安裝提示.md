# PWA安裝提示

## 決策
還沒安裝時，首頁上方顯示「把 healbuddy 加到主畫面」卡片；瀏覽器支援就提供「一鍵安裝」，不支援就依手機和瀏覽器顯示對應的安裝步驟。

## 原因
使用者要求加入 PWA 安裝提示，教使用者怎麼安裝，能一鍵安裝更好。這推翻了先前「不做 iOS 安裝教學」的取捨（當時只記在計劃書的非目標，沒有獨立實體）。

## 範圍與限制
- 一鍵安裝：只有 Android / 桌面的 Chrome、Edge 支援（`beforeinstallprompt`）。iPhone 上的任何瀏覽器都不支援，只能顯示步驟。
- 步驟依平台分成：iPhone Safari、iPhone 其他瀏覽器（Chrome 等）、Android、桌面。
- 已從主畫面開啟（standalone）或已安裝時不顯示。
- 首頁卡片可按 ✕ 關閉，關閉後不再出現（記在這支手機的瀏覽器裡）；品項頁一直保留同一張卡片，隨時可以回來看。

## 對實作的影響
- `InstallState` 在 App 啟動時就建立，才接得到最早觸發的 `beforeinstallprompt`。
- 平台判斷依 userAgent；iPad 的桌面模式以觸控點數辨識。
- 測試：各平台步驟、一鍵安裝、取消安裝、已安裝隱藏、關閉後不再出現，見 [[前端測試]]。

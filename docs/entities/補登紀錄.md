# 補登紀錄

## 決策
紀錄頁的「今日」檢視可以切換到任一天，在那一天刪除紀錄，也能補登多吃的品項和運動。

## 原因
使用者要求紀錄頁的今日檢視也要能刪除紀錄和補登紀錄。

## 範圍與限制
- 刪除：每筆多吃、每項運動旁都有 ✕，點了立刻刪除；畫面下方會出現幾秒「已刪除・復原」提示，不另外跳確認視窗。
- 補登：點「＋ 補登這一天」後，從底部滑出和首頁一樣的快速記錄面板（品項按鈕、運動按鈕），點一下就記進所選的那一天。
- 只能補登今天和過去的日期，不能記未來的日期。
- 補登的多吃紀錄沒有時間，只記日期。
- 刪除或補登後，當天的 [[胖胖等級]] 和本週 / 本月統計立刻更新。

## 對實作的影響
- `IntakeEntry.time` 允許為空；補登的紀錄不填時間，清單中不顯示時間。
- 首頁和補登面板共用同一個快速記錄元件，只差在寫入的日期。
- 日期以 [[午夜換日]] 的本地日期為準。
- 測試需涵蓋：補登到過去日期、刪除後復原、未來日期無法補登、補登後胖胖等級更新，見 [[前端測試]]。

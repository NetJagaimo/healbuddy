# 額外攝取記帳

## 決策
不記錄每一餐，只記錄「多吃」的東西（飲料、零食、正餐以外的食物），以及當天做了哪些運動；正餐不需記錄。只記「有沒有、幾樣」，不換算熱量（見 [[不記卡路里]]）。

## 原因
追蹤每餐吃什麼不切實際。真正該追蹤的是那些額外多吃的東西。

## 範圍與限制
- 食物品項：使用者自行新增品項名稱，之後一鍵記錄（見 [[有紀錄比沒紀錄好]]）。
- 運動：一個按鈕 = 今天有運動，不管做什麼、做多少。預設項目：健身房、爬山、走路 8000 步以上、游泳，可自訂（見 [[運動項目管理]]）；規則見 [[運動打卡規則]]。
- 每日狀態以 [[胖胖等級]] 呈現；日期以 [[午夜換日]] 劃分。
- 不包含：正餐記錄、熱量、營養素分析、運動時長或距離。

## 對實作的影響
- 資料模型：`FoodItem`（名稱）、`IntakeEntry`（日期、品項、時間）、`ExerciseCheck`（日期、運動項目）。

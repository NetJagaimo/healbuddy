# 離線使用

## 決策
App 完全在本機運作：打開網頁、安裝 [[PWA]] 後即可使用，資料只存在該裝置上，不做任何聯網同步。

## 原因
現階段只需要「打開網頁安裝 PWA，然後使用」就夠了，不需要任何聯網同步功能。

## 範圍與限制
- 包含：所有功能在無網路時可用；資料存在瀏覽器本機儲存（IndexedDB）。
- 不包含（現階段）：帳號登入、雲端同步、跨裝置共用資料、後端伺服器。
- 風險：清除瀏覽器資料或換手機會遺失紀錄 → 提供「匯出 / 匯入 JSON」作為手動備份。

## 對實作的影響
- 不設計任何 API 或後端；所有資料讀寫走本機儲存層。
- 需呼叫 `navigator.storage.persist()` 降低資料被瀏覽器清除的機率。
- 資料格式要帶版本號，方便未來加入同步時遷移。

## 考慮過的替代方案
- Firebase / Supabase 雲端同步 — 現階段沒有需求，徒增複雜度與隱私顧慮。

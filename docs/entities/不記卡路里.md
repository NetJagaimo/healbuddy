# 不記卡路里

## 決策
App 完全不記錄、不計算、不顯示卡路里。食物品項只有名稱，運動只有項目；畫面上只呈現「吃了哪些品項」與「做了哪些運動」。

## 原因
使用者希望淡化卡路里數字，只顯示品項。畫面上不出現數字後，熱量就沒有任何用途，因此決定不保留。這也是 [[有紀錄比沒紀錄好]] 的延伸：少填一格，記錄更快。

## 範圍與限制
- 首頁只保留：快速記錄（吃的、運動）＋ 今日紀錄清單。
- 紀錄頁分為今日 / 本週 / 本月三個檢視，用 [[胖胖等級]] 的 emoji 與運動 emoji 呈現，不顯示任何熱量或收支數字。
- 不包含：熱量輸入欄、收支結餘、燈號、每日額度。

## 對實作的影響
- 資料模型移除所有 `kcal` 欄位。
- 新增品項只需填名稱。
- 統計只計「次數 / 樣數 / 天數」。

## 考慮過的替代方案
- 保留熱量於資料中、畫面不顯示 — 每個品項要多填一格，卻沒有用途。
- 用熱量計算紅黃綠燈號 — 使用者改選依樣數顯示的 [[胖胖等級]]。

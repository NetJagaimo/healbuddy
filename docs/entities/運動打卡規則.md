# 運動打卡規則

## 決策
一天做了兩種（或更多）運動，每一種各記一筆，當日紀錄與 emoji 全部並列顯示。同一種運動同一天只記一筆（按一下打卡，再按一下取消）。

## 原因
使用者原話：「一天兩種就兩種都記一個紀錄，然後加總」。

## 範圍與限制
- 例：同日健身房 + 走路 8000 步 → 紀錄兩筆，顯示 🏋🚶。
- 不包含（現階段）：同一項目一天記多次（例如一天去兩次健身房）。

## 對實作的影響
- `ExerciseCheck` 以（日期, 運動項目）為唯一鍵。
- 運動按鈕是切換開關；多個按鈕可同時為「已按下」。
- 測試：多項並列、同項重複按為取消，見 [[前端測試]]。
